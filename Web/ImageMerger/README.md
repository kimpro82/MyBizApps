# [Image Merger v1.0 Beta](../../README.md)

**Date:** 2026.09.08

A browser-based image merger and grid layout utility built with TypeScript and Vite.
All image processing is performed locally in the browser; source images are not uploaded to a server.

## [Features](#list)

- Add multiple images by file selection or drag and drop
  - PNG, JPEG, WebP, GIF, SVG, and AVIF input formats are accepted
- Arrange images using several layout modes
  - Automatic grid
  - Horizontal merge
  - Vertical merge
  - Custom column count
- Standardize image dimensions without cropping
  - Exclude unusually large outliers
  - Equalize dimensions by row
  - Preserve each image's original size
- Apply per-image transformations
  - Scale from 0.2x to 2.0x
  - Horizontal flip
  - Vertical flip
  - 90-degree rotation
  - Drag and drop reordering
- Configure the merged canvas
  - Image spacing
  - Outer padding
  - Transparent background
  - Grayscale background presets
  - Custom color picker with a rainbow color indicator
  - Optional aspect-ratio distortion
- Preview and export the result
  - Fit-to-screen, zoom-in, and zoom-out controls
  - PNG, JPEG, and WebP output
  - Adjustable quality for JPEG and WebP
  - Copy the merged image to the clipboard
  - Download with a custom file name
- Manage the workspace efficiently
  - Collapse individual control panels
  - Reset all per-image transformations without deleting uploaded images
  - Clear all uploaded images with confirmation


## [Usage](#list)

1. Open the application in a modern browser.
2. Add one or more image files using the upload area.
3. Choose a layout mode and adjust spacing, padding, and background settings.
4. Use the controls in the uploaded-image list to transform or reorder individual images.
5. Select an export format and file name.
6. Download the merged image or copy it to the clipboard.

The first panel, `Add Images`, is expanded by default. Other control panels can be opened by selecting their titles.


## [Development](#list)

### Prerequisites

- Node.js and npm
- A modern browser with Canvas API support

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Vite will print the local development URL in the terminal.

### Build the application

```bash
npm run build
```

The build command performs the following steps:

- Type-checks the TypeScript source with `tsc`
- Bundles the application with Vite
- Compiles TypeScript files into `dist-js/` through `compile.sh`

### Preview the production build

```bash
npm run preview
```

## [Implementation Notes](#list)

- Image files are decoded with the browser's `FileReader` and `HTMLImageElement` APIs.
- The merged result is rendered with the Canvas 2D API.
- Image transformations are applied during rendering, so the original source image remains unchanged.
- The `outlierMax` standardization mode uses the 1.5 IQR rule to prevent an unusually large image from determining every cell size.
- Clipboard copy depends on browser support for `ClipboardItem` and secure-context clipboard permissions.
